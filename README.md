 This C program demonstrates the use of pointers to add two numbers.
 It takes two integer inputs from the user.
 It declares three integer variables: `a`, `b`, and `sum`.
 It declares two pointer variables, `p1` and `p2`.
 It uses the address-of operator (`&`) to store the addresses of `a` and `b`.
 It uses pointer variables to access the values of the two numbers.
 It uses the dereference operator (`*`) to retrieve values from memory addresses.
 It adds the two numbers using pointer variables.
 It stores the calculated result in the `sum` variable.
Finally, it displays the sum using the `printf()` function.
